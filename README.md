# Márcio Jr. França Advocacia Jurídica

Site institucional oficial em React e Vite, preparado para implantação na Vercel.

## Desenvolvimento

```bash
npm ci
npm run dev
```

## Produção

```bash
npm run build
```

O conteúdo gerado fica em `dist/`. O processo de build pré-renderiza a home, as quatro páginas-pilar, contato e a página 404.
